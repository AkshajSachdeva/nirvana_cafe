# Nirvana Cafe project progress

## Current status

Core customer website, API, database schema/seed, and documentation are implemented. A self-contained `Nirvana_Cafe.html` preview has been generated. The project-local MySQL 8 instance is running on port 3307. Homepage booking, Asia/Kolkata past-time checks, one-table party capacity checks, and a visible reservation confirmation panel are implemented. The requested operations extension now adds role-scoped admin dashboards, synthetic staff/orders/monthly awards, and customer menu pre-orders.

## Scope decisions

- The initial master-prompt build was customer-facing. A later user request explicitly expanded it with staff administration and pre-orders; payment processing and live POS remain excluded.
- The database now has 19 entities, including separate admin accounts, staff, monthly awards, orders, and order items.
- Five Delhi NCR branches are fictional demo records with placeholder addresses and no real contact details.
- Peak hour data will be described as sample data or reflect saved reservations; no fabricated popularity metrics.

## Stack and prerequisites

- Node.js 20+ and npm, React + Vite, Express, MySQL 8.0+, and `mysql2`. A project-local database uses `.mysql/data` and port 3307; the user-installed service was not modified.
- Copy `.env.example` to `server/.env`, create the database, then run the documented schema and seed commands.
- Exact prerequisites and commands are in `README.md`.

## Database and migration status

- Implemented schema and deterministic branch/menu/plan seed for 14 entities.
- One fictional demo account owns 150 demo test reservations: two daily reservations at each of five branches for 15 upcoming dates. Each generated row has `is_demo=TRUE` and a special request stating it is not a real booking. Each branch has 8 tables (4×2 seats, 2×4 seats, 1×6 seats, 1×8 seats); a booking uses one available table that fits the whole party. Generated reservations block an 8-seat table at 12:00 and a 6-seat table at 12:30 daily. An additional confirmed 8-person booking is saved for flow verification.
- The existing Windows `MySQL80` service remains stopped and untouched. A separate project-local MySQL 8.0.46 server is running on `127.0.0.1:3307` from the ignored `.mysql/data` directory. Schema and branch/menu seed are loaded.
- Admin demo data is applied in MySQL: one super admin, five branch admins, 30 mock staff, seven monthly staff awards per branch, and 880 generated sample orders across recent and upcoming dates. Customer menu pre-orders are assigned to the least-loaded active staff member for that date within a transaction.
